# Entrevista — Curso "Como criar sites 3D com Claude"

Assunto (informado pelo autor): Como criar sites 3D com Claude.
Público (informado pelo autor): Iniciantes no vibecoding.

## 1. Experiência e ferramentas
**P:** Que sites você já criou e que ferramentas usa?
**R:** Já criei vários tipos de site, de página básica a sistema interativo 3D. Geralmente uso o GitHub pra repositório, a Vercel pra deploy e hospedagem e o Claude pra fazer todo o trabalho.

## 2. Aluno ideal
**P:** Quem é o aluno ideal? Já programou? Já usou IA? Quer o site para quê?
**R:** Aquele entusiasmado em aprender e ansioso por vender sites. Usa só o GPT para coisa básica, dúvidas simples; nunca explorou a fundo o poder das IAs, seja GPT ou Claude. Objetivo: criar sites para vender.

## 3. Resultado final do aluno
**P:** O que o aluno terá feito e saberá fazer sozinho ao terminar?
**R:** Vai saber criar o próprio site do zero usando o Claude e outras ferramentas, podendo ter renda extra com isso ou até usar como renda principal.

## 4. Passo a passo real (da ideia ao site no ar)
**P:** Qual é o seu processo, na ordem?
**R:**
1. Vejo várias referências no TikTok ou no site onde ficam os sites premiados como os melhores do mundo.
2. Pego as informações e tento extrair toda a base daquele site, para entregar algo no mesmo nível.
3. Converso com o Claude, ajustando detalhes visuais, travamentos e afins.
4. GitHub.
5. Vercel.
6. Se o cliente fechar a compra: compra do domínio, que fica por conta do cliente.

## 5. Como conversa com o Claude
**P:** Que prompts você usa? Claude.ai, Claude Code ou os dois?
**R:** Uso os dois. Não uso um prompt pronto: não existe prompt milagroso, vai tudo da sua imaginação. Quando você olha algo, imagine aquilo virando um produto que vende. Não acredite em prompt milagroso que vai fazer seu site vender rios; tudo é questão de estudo, de aprender os efeitos no nosso outro curso e usar na prática.
(Observação: o autor menciona um "outro curso" dele, sobre efeitos.)

## 6. Erros mais comuns de iniciantes
**P:** Quais erros você mais vê?
**R:**
- Querer pedir tudo de uma vez ao Claude sem antes mandar uma referência do que quer.
- Não estudar os efeitos nem saber o nome de cada um antes de pedir; assim você só gasta token à toa.
- Principalmente: não revisar os lags (travamentos) do site no celular. Isso faz perder cliente.
- Não revisar cada detalhe: defeitos como imagem grande demais e afins.

## 7. Como corrige quando quebra/trava
**P:** O que você faz e manda para o Claude quando algo quebra?
**R:** Mando o print, a mensagem de erro e o link, e peço a referência em detalhes. Se vejo que ele continua errando, peço para outra IA corrigir e refazer um prompt para eu mandar ao Claude corrigir.

## 8. Exemplos e projetos de referência
**P:** Que exemplos você usa para ensinar?
**R:** Um site que uso bastante de referência, feito todo em HTML e CSS, que uso como inspiração para um dia chegar naquele nível: o "Pear" (da maçã), hospedado na Vercel. Não foi feito por mim. Penso que, se eu comprasse um site e me entregassem algo naquele nível, eu ficaria muito feliz e recomendaria o serviço sempre.
Link: https://pear.no/

## 9. Dinheiro: primeiro cliente, preço e venda
**P:** Como conseguir o primeiro cliente e quanto cobrar?
**R:**
- Prospecção pelo Google Maps.
- Nunca oferecer só o site e acabou: geralmente é um combo (site + alinhamento do Google Meu Negócio, etc.), e o cliente escolhe qual quer.
- Valores dependem do negócio: site de algo padrão, de R$ 2 mil para cima; landing page básica, no mínimo R$ 500.
- Prazo: geralmente uma semana.
- Dados levantados num briefing antes, junto com a assinatura do contrato pelo cliente.
